# 글로벌중학교 교사 연수 자료실

학생 AI 자료 검증 지도와 AI 콘텐츠 제작 실습을 위한 정적 웹 자료입니다.

- index.html: 연수생 자료실
- data.js: 교과별 OVT 시나리오와 실습 요청문
- downloads/강사용_원고.md: 설명·실습·질문을 포함한 강사용 원고

## GitHub Pages
Settings → Pages → Build and deployment에서 Deploy from a branch를 선택하고 main / (root)를 지정합니다.
예상 주소: https://emelmusekor.github.io/261028gm/

별도 설치나 빌드 없이 사용할 수 있습니다. 검증 기록은 사용자의 브라우저에만 저장하며 서버로 전송하지 않습니다.
게임의 수치와 정책 효과는 실습을 위한 가상 값입니다.
OVT는 이 연수에서 사용하는 수업 설계 틀이며 표준화된 평가 척도가 아닙니다.

## 수정
시나리오와 요청문은 data.js, 화면 동작은 app.js, 디자인은 style.css에서 수정합니다.
